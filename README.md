# CarRentalSystem_WithValdidation

## Overview
A C# console application that implements a car rental system with input validation.

## Purpose
This project demonstrates object-oriented design for a rental business domain, including vehicle management, customer interactions, and robust input validation. It serves as a practical exercise in C# programming for handling real-world style business logic and data integrity.

## Features
- Car rental operations
- Input validation to ensure data quality
- Console-based user interface

## How to Run
```bash
dotnet run
```
